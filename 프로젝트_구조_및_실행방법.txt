■ 개요
--------------------------------------------------------------------------------
  Chat Cursor는 Ruby on Rails 8.1 기반의 실시간 웹 채팅 애플리케이션입니다.
  PostgreSQL 데이터베이스를 사용하며, Turbo Streams + Action Cable로
  메시지를 실시간으로 전송합니다.

  관리자(admin) 계정으로 로그인하면 회원 목록 조회 및 회원 삭제 기능을
  사용할 수 있습니다.


■ 기술 스택
--------------------------------------------------------------------------------
  - Ruby on Rails 8.1.3
  - PostgreSQL (chat-cursor)
  - Puma 웹 서버 (포트 3001)
  - Hotwire (Turbo + Stimulus)
  - bcrypt (비밀번호 암호화)
  - Propshaft (에셋 파이프라인)
  - Solid Cable / Solid Cache / Solid Queue


■ 사전 요구사항
--------------------------------------------------------------------------------
  1. Ruby 4.x
  2. Rails 8.x
  3. PostgreSQL (localhost:5432)
  4. Bundler

■ 데이터베이스 테이블
--------------------------------------------------------------------------------

  [users] 사용자
    - id              : bigint (PK)
    - username        : string (unique, NOT NULL)
    - password_digest : string (NOT NULL)
    - admin           : boolean (default: false, NOT NULL)  ← 관리자 여부
    - created_at      : datetime
    - updated_at      : datetime

  [rooms] 채팅방
    - id              : bigint (PK)
    - name            : string (unique, NOT NULL)
    - description     : text
    - created_at      : datetime
    - updated_at      : datetime

  [messages] 메시지
    - id              : bigint (PK)
    - body            : text (NOT NULL)
    - user_id         : bigint (FK -> users)
    - room_id         : bigint (FK -> rooms)
    - created_at      : datetime
    - updated_at      : datetime

  관계:
    User    has_many :messages, dependent: :destroy
    Room    has_many :messages
    Message belongs_to :user, :room


■ URL 경로
--------------------------------------------------------------------------------

  [인증]
  GET    /                    채팅방 목록 (로그인 필요, root)
  GET    /login               로그인 화면
  POST   /login               로그인 처리
  DELETE /logout              로그아웃
  GET    /signup              회원가입 화면
  POST   /signup              회원가입 처리

  [채팅]
  GET    /rooms               채팅방 목록
  POST   /rooms               채팅방 생성
  GET    /rooms/:id           채팅방 입장 (실시간 채팅)
  POST   /rooms/:id/messages  메시지 전송

  [관리자] (admin 권한 필요)
  GET    /admin/users         회원 목록
  DELETE /admin/users/:id     회원 삭제


■ 실행 방법
--------------------------------------------------------------------------------

  [1] 프로젝트 폴더로 이동

      cd C:\ai\chat\proj01-cursor


  [2] gem 설치 (최초 1회 또는 Gemfile 변경 시)

      bundle install

      * gem은 vendor/bundle 폴더에 설치됩니다.


  [3] 데이터베이스 생성 및 마이그레이션 (최초 1회)

      bundle exec rails db:create
      bundle exec rails db:migrate
      bundle exec rails db:seed

      * db:seed 실행 시 테스트 계정과 샘플 채팅방이 생성됩니다.


  [4] (선택) 마이그레이션만 다시 적용할 때

      bundle exec rails db:migrate


  [5] 웹 서버 실행

      bundle exec rails server

      또는 포트를 직접 지정:

      bundle exec rails server -p 3001


  [6] 브라우저 접속

      http://localhost:3001

■ 주요 기능
--------------------------------------------------------------------------------

  1. 회원가입 / 로그인
     - bcrypt로 비밀번호 암호화
     - 세션(session) 기반 인증

  2. 채팅방 관리
     - 채팅방 목록 조회
     - 새 채팅방 생성 (이름, 설명)

  3. 실시간 채팅
     - Turbo Streams + Action Cable 사용
     - 메시지 전송 시 같은 방의 모든 사용자에게 즉시 표시
     - 새로고침 없이 메시지 수신

  4. 관리자 회원 관리 (admin 계정 전용)
     - 메인 화면에 "회원목록" 버튼 표시
     - 전체 회원 목록 조회 (아이디, 가입일)
     - 회원 삭제 (확인 대화상자)
     - 안전장치:
       · 본인 삭제 불가
       · 마지막 관리자 삭제 불가
       · 삭제 시 해당 회원의 메시지도 함께 삭제

  5. UI
     - 다크 테마
     - 반응형 레이아웃


■ 인증 / 권한 흐름
--------------------------------------------------------------------------------

  로그인 → session[:user_id] 저장
         → current_user 로 현재 사용자 조회
         → admin? 로 관리자 여부 확인 (users.admin 컬럼)
         → require_login / require_admin 으로 접근 제어


■ 자주 쓰는 Rails 명령어
--------------------------------------------------------------------------------

  bundle exec rails server          # 서버 실행
  bundle exec rails db:migrate      # 마이그레이션 적용
  bundle exec rails db:seed         # 시드 데이터 입력
  bundle exec rails db:reset        # DB 초기화 + migrate + seed
  bundle exec rails routes          # 전체 URL 목록 확인
  bundle exec rails routes -g admin # admin 관련 URL만 확인
  bundle exec rails console         # Rails 콘솔
  bundle exec rails dbconsole       # PostgreSQL 콘솔

■ Docker 배포 (앱: 다른 PC / DB: 이 PC)
--------------------------------------------------------------------------------

  1. .env.example 을 .env 로 복사 후 DB_PASSWORD, RAILS_MASTER_KEY 설정
  2. DB PC: PostgreSQL 원격 접속 허용 + db/setup_production_databases.sql 실행
  3. 앱 PC: .env 에 DB_HOST=DB PC IP, APP_HOST=앱 PC IP:3001 설정
  4. docker compose up --build -d

  자세한 내용: README.md 참고


■ 문제 해결
--------------------------------------------------------------------------------

  Q. "Could not find ... in locally installed gems" 오류
  A. bundle install 실행

  Q. DB 연결 오류
  A. PostgreSQL 서비스 실행 여부 확인
     config/database.yml의 접속 정보 확인

  Q. 포트 충돌
  A. config/puma.rb에서 포트 변경 (기본값: 3001)
     또는: bundle exec rails server -p [포트번호]

  Q. VIPS 경고 메시지
  A. 이미지 처리 라이브러리 관련 경고로, 채팅 기능에는 영향 없음

  Q. admin으로 로그인했는데 회원목록 버튼이 안 보임
  A. bundle exec rails db:migrate 실행 후
     admin 계정의 admin 컬럼이 true인지 확인
     (시드: bundle exec rails db:seed)
